GitHub トークン

プライベートリポジトリの閲覧、下書き（pending review）の操作、API レート制限の緩和（60 → 5,000 req/h）に使います。 トークンはこの端末の chrome.storage.local にのみ保存され、送信先は api.github.com のみです。

fine-grained personal access token を推奨します。1 つのトークンでアクセスできるのは 1 つの owner（ユーザー / Organization）配下だけなので、 owner ごとに 1 つずつ登録してください。必要な権限は次の 3 つです。

  • Pull requests: Read and write — PR 情報の取得と下書き・レビュー投稿
  • Contents: Read-only — ファイル内容の取得（解析対象）
  • Metadata: Read-only — リポジトリの基本情報（他の権限を選ぶと自動で付きます）

Repository access で解析したいリポジトリを選択するのを忘れないでください。 選択から漏れたリポジトリは、権限不足ではなく「見つかりません（404）」として扱われます。
